# 第二十一届全国大学生智能汽车竞赛 - 轮腿穿越组开源方案 (飞雷神队)

## 📌 项目简介

本项目为吉林师范大学“飞雷神队”参与第二十一届全国大学生智能汽车竞赛（轮腿穿越组）的硬件与底层算法开源方案。系统以逐飞科技 V 型车模为基础平台，搭载英飞凌 CYT4BB7 微控制器作为核心控制单元，成功开发了一套具备高机动性与高稳定性的轮腿式运动控制系统。 受限于备赛周期，目前的摄像头视觉方案与全局速度调度策略尚有较大的优化空间。为保证开源内容的质量与参考价值，这两部分模块暂不包含在本次开源仓库中，敬请谅解。

## 🧰 硬件系统架构

为了提高系统的可维护性与抗干扰能力，硬件系统采用了模块化解耦设计，分为以下五大核心板块：

* **主控板 (CYT4BB7)**：系统核心枢纽。板载基于 SCT2450 的 12V 转 5V 主供电网络，以及两路独立的 RT9013-33 LDO 为逻辑器件和摄像头（总钻风 MT9V034）提供纯净的 3.3V 供电。电源入口设计有基于 HY19P03 MOSFET 的固态电子开关。
* **舵机驱动板**：采用分布式供电方案，搭载 4 颗 SCT2450STER 同步降压芯片，为 4 个舵机提供”一对一”的独立 7.4V 电源，彻底避免多舵机联动时的电源耦合干扰。
* **无刷双驱板**：电源管理端配有 RY9121E 降压芯片与 TVS 瞬态抑制二极管。驱动级采用 FD6288Q 预驱芯片与超低内阻的 TPN2R703NL 贴片 MOSFET，构建双三相逆变桥，以应对急刹车与瞬间大电流爆发需求。
* **磁编码器板**：基于英飞凌 TLE5012B 巨磁阻 (GMR) 传感器，并经过 LDO 降压与硬件阻抗匹配设计，实现转子位置的高精度采集。
* **核心传感器**：包含 TOF (DL1D) 激光测距模块以及 IMU660RA/RC 陀螺仪。

## 🧠 核心软件与算法

软件系统不仅依赖逐飞底层库的数据采集支持，更自主实现了多项复杂的闭环算法：

* **姿态解算与数据融合**：
  * 设计了基于 ARM 内核 DWT 周期计数器的纳秒级时间戳，解决了积分周期抖动问题。
  * 采用带有防干扰机制的动态 PI 调节 Mahony 互补滤波算法。当检测到加速度模长异常（偏离 3500-4500 区间）时，算法自动切断 PI 调节，纯靠陀螺仪维持姿态，完美解决车模剧烈震荡下的姿态发散问题。
* **三闭环串级控制架构**：
  * **外环（速度环 100Hz）**：解算平均车速，直接控制 BDS300 舵机动态调节机械重心以抑制”溜车”。
  * **中环（角度环 200Hz）**：基于真实俯仰角 (Pitch)，跟踪静态机械零点，平滑补偿重心调节带来的角度偏移。
  * **内环（角速度环 1kHz）**：高频中断内运行，直接抽取 Y 轴原始角速度转化为无刷电机的 PWM 占空比，保障极致的动态自平衡。
* **自主导航与路径规划**：
  * 依靠融合磁编码器与 IMU 偏航角的航位推算法 (Dead Reckoning) 建立全局二维坐标系。
  * 导航任务分为“航线预采集”与“实时追踪”两个阶段，通过欧氏距离计算与反三角函数(atan2)实时计算横向航向偏差和纵向期望距离，实现点到线的高效轨迹追踪。

## 🛠 开发与调试工具

* **IDE**：IAR Embedded Workbench 结合 VS Code 跨平台协同编码。
* **调试监控**：利用逐飞串口助手与 VOFA+ 上位机实现 PID 参数的动态观测与波形实时绘制。
